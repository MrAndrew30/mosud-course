# Практическая работа №14. EXPLAIN ANALYZE и оптимизация запросов

Карпов А.С., ИНБО-20-23. Вариант 9.

Задача: оптимизировать запрос с приведением числового столбца к text, сохранив результат.

Исходное условие price::text = '100.00' заменено на price = NUMERIC '100.00'. Для поиска создан B-tree индекс по price.

Оба запроса возвращают 172 позиции. EXCEPT в обе стороны дал 0 различий.

План изменился с Seq Scan на Bitmap Heap Scan с использованием индекса. В зафиксированном запуске обращения к буферам сократились с 2320 до 138. Устранены преобразования цены для всех строк таблицы.

Подробное сравнение планов приведено в SQL. Тестовый индекс удаляется в конце файла.
