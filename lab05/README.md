# Практическая работа №5. Кванторы, EXISTS и реляционное деление

Карпов А.С., ИНБО-20-23. Вариант 9: S = {PB, RN, PE}.

Задача: найти категории товаров, встречавшиеся в доставленных заказах покупателей каждого штата из S.

| Реализация | Категорий |
|---|---:|
| Двойной NOT EXISTS | 38 |
| GROUP BY / HAVING | 38 |
| EXCEPT / NOT EXISTS | 38 |

EXCEPT-проверки в обе стороны подтвердили совпадение результатов.

Для категории alimentos получено: PB — 2 заказа, PE — 8, RN — 2.

При пустом target_states все три решения возвращают 73 категории. Обязательных штатов нет, поэтому условие выполняется для каждой категории. В реализации GROUP BY кандидаты сохраняются через LEFT JOIN.
