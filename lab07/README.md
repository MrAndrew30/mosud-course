# Практическая работа №7. NULL, трёхзначная логика и качество данных

Карпов А.С., ИНБО-20-23. Работа без вариантов.

Задача: исследовать пропуски в данных и поведение SQL-выражений с NULL.

Подсчитаны NULL в необязательных столбцах orders, products и order_reviews. Сравнены COUNT(*), COUNT(column), проверки NULL, NOT IN и NOT EXISTS, фильтры LEFT JOIN в ON и WHERE. Использованы IS DISTINCT FROM, COALESCE и NULLIF.

При наличии NULL в temp_ids запрос NOT IN вернул 0 заказов, а NOT EXISTS — 99440.

| Показатель качества | Доля |
|---|---:|
| Заказы без фактической даты доставки | 2,98% |
| Товары без категории | 1,85% |
| Отзывы без текста | 58,71% |

Отсутствие даты у недоставленного заказа может быть естественным. Отсутствие категории у товара указывает на неполную классификацию.
