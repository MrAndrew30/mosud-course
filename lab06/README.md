# Практическая работа №6. Подзапросы и логика предикатов

Карпов А.С., ИНБО-20-23. Вариант 9.

Задача: найти штаты, средняя фактическая длительность доставки в которых выше общей средней.

Длительность рассчитывается как разность фактической даты доставки и даты покупки. Учитываются доставленные заказы с заполненными датами.

Основное решение использует скалярные и коррелированные подзапросы, а также EXISTS. Альтернативное решение выполняет предварительную агрегацию через CTE.

Оба решения возвращают 24 штата. EXCEPT в обе стороны по штату, числу доставок и средней длительности дал 0 различий.

Отдельный запрос с ALL нашёл 36377 доставок длительнее общей средней.
