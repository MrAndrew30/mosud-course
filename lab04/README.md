# Практическая работа №4. Соединения отношений и сложные JOIN

Карпов А.С., ИНБО-20-23. Вариант 9.

Задача: рассчитать стоимость доставки по категориям товаров и штатам покупателей.

Соединены customers, orders, order_items и products. Для каждого соединения указана кратность. Через LEFT JOIN сохранены заказы без отзывов, отдельным запросом найдены заказы, у которых отзывов нет.

Прямое соединение позиций и платежей по order_id размножило строки: 117601 вместо 112650. Сумма доставки увеличилась с 2251909,54 до 2357428,51.

После предварительной агрегации обеих таблиц по order_id правильная сумма восстановлена.
