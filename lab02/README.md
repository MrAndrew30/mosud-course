# Практическая работа № 2

Вариант 9: множество A — товары доставленных заказов клиентов из `PA`, множество B — из `AM`.

| Результат | Мощность |
|---|---:|
| A | 864 |
| B | 145 |
| A ∪ B | 986 |
| A ∩ B | 23 |
| A − B | 841 |
| B − A | 122 |

В исходных выборках найдено 1054 строки для `PA` и 163 строки для `AM`. `UNION` множеств A и B возвращает 986 уникальных товаров, а `UNION ALL` - 1009 строк, поскольку 23 общих товара сохраняются дважды. Если дополнительно убрать `DISTINCT` из A и B, `UNION ALL` возвращает 1217 строк при 986 различных товарах, то есть 231 повторную строку.
